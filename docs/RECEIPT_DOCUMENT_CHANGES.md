# «سند استلام المشتريات» — إغلاق فجوة طباعة سند الاستلام (RCV)

**التاريخ:** 2026-07-22

## الهدف

سند الاستلام (RCV) كان يُولَّد رقمه ويُحفظ بقاعدة البيانات لكن **بلا مستند رسمي قابل للطباعة**. أُنشئ الآن مستند «سند استلام المشتريات» الذي يوثّق العملية كاملة من رفع فاتورة المورد وتحليل OCR حتى الحفظ وطباعة الباركود، ويشمل:

- رقم السند `RCV-YYYY-NNNN` + رمز QR له
- طلب الشراء المرتبط (أو «استلام مستقل» إن لم يوجد)
- بيانات المورد وفاتورته: الاسم، الرقم الضريبي، رقم الفاتورة، تاريخها
- مصدر الإدخال: تحليل OCR (مع نسبة الثقة) أو إدخال يدوي — ولكل بند على حدة (OCR / يدوي / OCR+تعديل)
- جدول الأصناف: الاسم، **الكود الداخلي `INV-…`**، **باركود المصنع** (سواء وُلّد آليًا أو أُدخل يدويًا — كلاهما من نفس حقل `inventory.manufacturerBarcode`)، الكمية والوحدة، سعر الوحدة، الضريبة، إجمالي البند
- الإجماليات (قبل الضريبة / الضريبة / الكلي)
- الفروقات المسجّلة وملاحظات الاستلام
- اسم أمين المستودع المستلم + خانتا توقيع
- عدّاد مرات الطباعة (بنفس نمط وثيقتي التسليم والمرتجع)

## ما لم يتغير
- لا تغيير على منطق الاستلام أو إدخال المخزون أو توليد الأرقام — الإضافتان قراءة/عدّاد فقط
- لا صلاحيات جديدة (نفس `warehouseProcedure` المستخدم بباقي إجراءات السندات)
- مسارات الاستلام الثلاثة كلها مغطاة (مرتبط بطلب شراء / مستقل / اعتماد مسودة)
