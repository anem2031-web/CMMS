# المسار C — دورة صيانة الأصول خارج الشركة

## النطاق

ينظم هذا التطوير حركة الأصل منذ اعتماد المسار C وحتى إعادته إلى موقعه وإغلاق البلاغ، مع فصل واضح بين مسؤوليات المستودع والحراسة والمندوب والفني والمدير.

## دورة العمل المعتمدة

1. **اعتماد الفحص واختيار المسار C**
   - يشترط اعتماد نتيجة الفحص وكتابة مبرر الصيانة الخارجية.
   - ينتقل الإجراء إلى المستودع.

2. **تجهيز الأصل بواسطة المستودع**
   - اسم الأصل، صورة قبل الخروج، وصف الحالة، المندوب المسؤول: حقول إلزامية.
   - يصدر رقم وثيقة خروج من نوع `EXT-OUT`.
   - لا يظهر إجراء الخروج للحراسة قبل هذه الخطوة.

3. **موافقة الحراسة على الخروج داخل النظام**
   - اسم حامل الأصل إلزامي.
   - اسم الحارس والتاريخ والوقت يؤخذون من حساب الدخول والخادم.
   - عند الموافقة ينشئ النظام دورة مالية مرتبطة بالبلاغ والمندوب، ويصبح الأصل `out_for_repair`.

4. **دورة المندوب المطابقة لمسار B**
   - التسعير وحفظ السعر.
   - الإرسال للحسابات.
   - اعتماد الحسابات ثم الإدارة.
   - تأكيد إتمام الصيانة الخارجية مع صورة الأصل بعد الصيانة ومرفق الفاتورة/التقرير من واجهة التنفيذ المعتادة.
   - تظهر المهمة للمندوب المحدد فقط، مع بقاء صلاحيات الإدارة والمالك.

5. **موافقة الحراسة على الدخول بعد الإصلاح**
   - لا تظهر قبل أن يؤكد المندوب اكتمال الصيانة الخارجية.
   - اسم الشخص الذي أعاد الأصل إلزامي.
   - اسم الحارس والتاريخ والوقت يسجلون آليًا.

6. **استلام المستودع للأصل العائد**
   - صورة الأصل بعد العودة ووصف حالته إلزاميان.
   - تقرير الورشة والملاحظات اختياريان.
   - يصدر رقم وثيقة استلام من نوع `EXT-RET`.

7. **تسليم الأصل لإعادة التركيب**
   - الفني المسند للبلاغ ظاهر وثابت وغير قابل للتعديل.
   - المستلم الفعلي حقل إلزامي، ويمكن أن يكون الفني المسند نفسه أو فنيًا/مسؤولًا بديلًا.
   - اختيار مستلم بديل لا يغير إسناد البلاغ.
   - يصدر رقم وثيقة تسليم من نوع `EXT-HND`.

8. **إعادة التركيب والإغلاق**
   - بعد التسليم فقط يظهر زر بدء إعادة التركيب.
   - بعد البدء تصبح الملاحظات والصورة بعد التركيب إلزاميتين.
   - ينتقل البلاغ إلى `ready_for_closure` ثم يغلقه المدير المخول.

- `delivered_for_reinstall`
- `reinstall_in_progress`
- `ready_for_closure`
- `closed`

## الحماية من تجاوز الدورة

- مسارات الحراسة القديمة داخل البلاغ محظورة من الخادم.
- لا خروج قبل وثيقة المستودع.
- لا دخول قبل اكتمال دورة المندوب.
- لا استلام مستودع قبل موافقة الدخول.
- لا تسليم للتركيب قبل استلام المستودع.
- لا بدء إعادة تركيب قبل التسليم.
- لا استخدام لإجراء الإصلاح العام القديم للمسار C.
- لا إغلاق قبل وصول سجل الصيانة الخارجية إلى `ready_for_closure` وحفظ الملاحظات والصورة.

## الوثائق

- وثيقة تسليم أصل للصيانة الخارجية وتصريح خروج.
- وثيقة استلام أصل عائد من الصيانة الخارجية.
- وثيقة تسليم أصل لإعادة التركيب.
- التقرير الأرشيفي النهائي للبلاغ يتضمن موافقتي الحراسة، المندوب، المستودع، المستلم الفعلي وأرقام الوثائق.
