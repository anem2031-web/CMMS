# اختبار PDF وتنبيه التسوية بعد تأكيد النشر

البيئة: رابط Railway الذي أكد صاحبه اتصاله بـcopycmms. جميع إجراءات الخدمة عبر واجهة المتصفح؛ لا اتصال قاعدة ولا طلبات API مبرمجة. اختبار الرابط المباشر استُخدم فيه شريط عنوان المتصفح.

| الحزمة DPB-2026-030001 | ظهر المندوب والتاريخ والحالة والطلب المرتبط PR-2026-210474 وتفاصيل صنفه؛ لا زر PDF قبل الاعتماد |

لم يُعتمد طلب مالي جديد من الوكيل. عند محاولة متابعة اعتماد الطلب التجريبي ذي الصنف «بويه تجربة»، أوقفت المراجعة الآلية إدخال مبلغ العهدة/اعتماد الحسابات، وصنفته إجراءً ماليًا يتطلب أن ينفذ المستخدم الخطوة النهائية بنفسه. لم يُستخدم مسار بديل ولم تُرسل موافقة عبر API. قيمة 0 وحدها لا تفعّل زر الاعتماد في الواجهة الحالية؛ لم يُغيّر هذا الشرط.

الحد المتبقي: التحقق من انتقال **المعاملة نفسها** قبل الاعتماد وبعده يحتاج اعتماد PR-2026-210474 يدويًا من RED4 ثم RED8. اختبارات الحالات القائمة أثبتت المنع قبل اعتماد المستخدم والتنزيل لوثيقة سبق أن اعتمدها، لكنها لا تُسجل بدلًا من اختبار انتقال جديد لم يُنفذ.
