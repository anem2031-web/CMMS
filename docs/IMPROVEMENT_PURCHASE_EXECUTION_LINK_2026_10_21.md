## التعديل المحلي
- زر «إنشاء بلاغ تنفيذ للتحسين» في تبويب المقترحات المعتمدة للفكرة قيد التنفيذ ذات طلب شراء وتتبع إصدار1 دون بلاغ مرتبط.

- الكاتب يقفل الفكرة ويعيد فحص حالتها، وصلاحية الدور الحالية، ووجود طلب الشراء وسياقه. لا يقبل طلبًا مسودة/مرفوضًا/ملغيًا، ولا موقعًا أو قسمًا أو أصلًا مخالفًا.
- حفظ البلاغ ورابطه ضمن المعاملة الحالية، دون استبدال رابط الشراء أو تغيير الطلب. تحديث شرطي يمنع التكرار؛ لا تصريح بإنشاء شراء ثانٍ. لا تغيير في صلاحيات القائمة أو API أو حراس الصرف/التكلفة.

- قيمة مشتريات الفكرة بقيت كما هي، دون إضافة صرف اللوت نفسه مرة أخرى. تقرير صافي مواد التنفيذ حسب الأصل يبقى منفصلًا: تكلفة اللوت المصروف، دون ضريبة الشراء أو المتوسط. لم نغير قواعد التقييم.
