# إصلاح: تجميد التوقيع لحظة إصدار الوثيقة (لا تعديل بأثر رجعي)

**التاريخ:** 2026-07-27

## المشكلة

التوقيع كان يُقرأ **حيًّا** من `users.signatureUrl` في كل عملية طباعة. فلو استُبدل توقيع مستخدم بعد صدور وثيقة قديمة، كانت إعادة طباعة تلك الوثيقة تُظهر **التوقيع الجديد** بدل التوقيع الذي كان صحيحًا فعليًا وقت صدورها — تعديل بأثر رجعي غير مقبول لوثائق مالية.

## الإصلاح: تجميد عند أول إصدار، ثم قراءة من التجميد فقط

أول مرة تُطبع فيها الوثيقة لطلب/دفعة معينة، يُحفظ التوقيع الحالي في عمود تجميد (Snapshot) مخصص. أي طباعة لاحقة تقرأ من هذا التجميد **وليس من ملف المستخدم الحالي**، فلا يتأثر بأي استبدال لاحق للتوقيع. الوثائق القديمة (المطبوعة قبل هذا الإصلاح) لا تُصحَّح بأثر رجعي — بقرارك، لا تهم.

### منطق التجميد لكل خانة

| الخانة | مكان التجميد | القاعدة |
|---|---|---|
| مقدّم الطلب | `purchase_orders.requesterSignatureSnapshot` | أول طباعة لهذا الطلب تُجمِّد توقيع المُقدّم الحالي |
| مراجع الطلب | `purchase_orders.reviewerSignatureSnapshot` | أول طباعة تُجمِّد توقيع المراجع الحالي |
| مستلم العهدة | `po_pricing_batches.delegateSignatureSnapshot` | أول طباعة **لدفعة محددة** تُجمِّد توقيع مندوبها |

إن لم يكن للشخص توقيع مرفوع أصلًا وقت أول طباعة، لا يُجمَّد شيء (يبقى فارغًا)، فإذا رفع توقيعه لاحقًا وأُعيدت الطباعة، يُجمَّد حينها تلقائيًا (أول ظهور فعلي للتوقيع هو ما يُجمَّد، وليس بالضرورة أول طباعة للوثيقة).

### استثناء معروف ومقصود
عند طباعة **نسخة الطلب كاملاً بلا تحديد دفعة** (لا يوجد `batchId`)، يبقى توقيع "مستلم العهدة" يُقرأ حيًّا كسلوك احتياطي — هذه حالة نادرة (تحدث فقط حين تكون كل أصناف الطلب لمندوب واحد ولم تُحدَّد دفعة عند الطباعة). التجميد الكامل يعمل فقط عند تحديد الدفعة، وهو المسار الأشيع فعليًا.

## الملفات

### جديدة (1)
- `drizzle/0048_signature_snapshots.sql` — هجرة إضافة الأعمدة الثلاثة

### معدّلة (2)
- `drizzle/schema.ts` — أعمدة `requesterSignatureSnapshot`, `reviewerSignatureSnapshot` (على `purchase_orders`)، و`delegateSignatureSnapshot` (على `po_pricing_batches`)
- `server/services/export/exportService.ts` — منطق "اقرأ من التجميد، وإن لم يوجد جمّد من القيمة الحية الآن" لكل خانة توقيع

## خطوة نشر مطلوبة

```sql
ALTER TABLE `purchase_orders`
  ADD COLUMN `requesterSignatureSnapshot` varchar(500) NULL COMMENT 'نسخة مجمَّدة من توقيع مقدّم الطلب لحظة أول إصدار للوثيقة',
  ADD COLUMN `reviewerSignatureSnapshot`  varchar(500) NULL COMMENT 'نسخة مجمَّدة من توقيع مراجع الطلب لحظة أول إصدار للوثيقة';

ALTER TABLE `po_pricing_batches`
  ADD COLUMN `delegateSignatureSnapshot` varchar(500) NULL COMMENT 'نسخة مجمَّدة من توقيع مستلم العهدة (المندوب) لحظة أول إصدار للوثيقة لهذه الدفعة';
```

التحقق:
```sql
SHOW COLUMNS FROM purchase_orders LIKE '%SignatureSnapshot%';
SHOW COLUMNS FROM po_pricing_batches LIKE '%SignatureSnapshot%';
```

## التحقق من الكود
- `tsc --noEmit`: 3 أخطاء بيئية فقط (تعريفات type مفقودة لأن `node_modules` غير مرفوع بالكامل في هذه الحزمة) — لا علاقة لها بملفاتنا، وصفر أخطاء من ملفاتنا
- فحص syntax مستقل عبر transpile للملف المعدَّل: نجح بلا أخطاء
