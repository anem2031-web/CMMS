# فحص قراءات قوائم الشراء والبلاغات والمخزون والكتالوج — 2026-10-20

## النطاق والحدود

فحص مصدر الكود واختبارات محلية معزولة. لا اتصال بقاعدة بيانات، ولا تعديل بيانات أو كود تشغيل، ولا اختبار متصفح أو قياس زمن Railway. لا يشمل كل إجراء في البرنامج. أضيف ملف اختبارات وأداة تشغيل فقط إلى جانب هذا التقرير.

- `node tools/read-scope-perf/audit-lists.mjs`: **97/97 ناجحة**، 5 ملفات: اختيار الكتالوج 55، أرصدته 20، واجهة الاختيار 7، حقل الرصيد 9، وعدد استعلامات المخزون/الرصيد 6.
- اختبارات العدد تستبدل ناقل القاعدة ببيانات اصطناعية، ولا تثبت سرعة التنفيذ على TiDB أو كفاية الفهارس. عدد الاستعلامات لا يقيس حجم نتائجها.

## المقترحات فقط — لم تنفذ

1. تقسيم قائمة المخزون على الخادم، واسترجاع آخر شراء وآخر صرف فقط بدل تحميل تاريخ الحركات المطابق كاملًا.
2. إعادة استخدام أصناف المندوب داخل نفس RPC لحساب الرؤية والعداد، دون ذاكرة صلاحيات مشتركة بين الطلبات.
3. قياس مسار الترجمات غير الموجودة قبل تقرير طريقة جعله غير حاجب للعرض.
4. قياس المتصفح بعد النشر للتفريق بين انتظار القوائم وملفات الصور والخدمات الخارجية.

لا أوامر SQL مطلوبة لهذا الفحص. لم تنفذ تحسينات التشغيل المقترحة أعلاه.
